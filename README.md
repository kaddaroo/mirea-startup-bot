# Стартап-клуб РТУ МИРЭА — бот

Бот для автоматизации мероприятий клуба: регистрация участников, запись на
мероприятия, система заданий и коинов, QR-подтверждение присутствия и
инструменты аналитики для организаторов.

## Статус
🚧 В разработке

## Стек
Python, aiogram 3, PostgreSQL, SQLAlchemy
