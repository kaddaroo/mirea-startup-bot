## I. Функционал для УЧАСТНИКОВ
ТЗ по проекту: Разработка ботов (Telegram и MAX) для Стартап-клуба РТУ МИРЭА

Цель: Автоматизация рутинных процессов, повышение конверсии и лояльности, сбор статистики.

I. Функционал для УЧАСТНИКОВ

1. Быстрая регистрация (Личный кабинет):
   · Пользователь регистрируется в боте один раз, указывая ФИО, ВУЗ, курс, направление обучения из обощенных групп из перечня (Бизнес, инженерия, химия, право...). С валидацией ввода и возможностью пользователю редактировать свои данные)
   · При последующих регистрациях на мероприятия эти данные подставляются автоматически.
2. Проверка подписки:
   · Перед регистрацией на мероприятие бот проверяет, подписан ли пользователь на основной Telegram-канал клуба. Если нет — выдаёт ссылку и просит подписаться. Это решает задачу роста аудитории.
3. Напоминания о мероприятии:
   · Автоматическая рассылка уведомлений за 24 часа до старта.
   · В уведомлении: напоминание о локации, времени и важных вещах (например, «не забудьте паспорт»).
4. Система заданий и накопления коинов:
   · Участник может выполнять задания из списка предложенных (например, сделать репост, опубликовать сторис с упоминанием клуба).
   · После выполнения задания он отправляет ссылку на проверку.
   · По возможности реализовать автоматизированную проверку условий задания. В ином случае администратор в панели управления подтверждает выполнение и начисляет коины.
5. Проверка баланса:
   · Участник может в любой момент посмотреть свой текущий баланс коинов в боте.

II. Функционал для ОРГАНИЗАТОРОВ (Административная панель)

1. Генерация QR-кодов для мероприятий:
   · Создание уникального QR-кода для каждого мероприятия.
   · Участники сканируют QR-код на входе, подтверждая своё присутствие. Это даёт честную статистику посещаемости.
+ возможность добавления посещения вручную, в случае ошибок со стороны системы
2. Выгрузка списка участников:
   · Возможность скачать файл (например, в формате .xlsx) со списком всех зарегистрировавшихся на конкретное мероприятие с их данными.
3. Аналитика:
   · Генерация уникальных ссылок для разных каналов продвижения (чат, канал, соцсети) 
   · Отслеживание количества регистраций и переходов по каждой ссылке. Это покажет, откуда приходит самая активная аудитория.
ИЛИ реализация посредством других методов
4. Общая выгрузка базы пользователей:
   · Возможность скачать полный список всех зарегистрированных в боте участников с их текущим балансом коинов.
