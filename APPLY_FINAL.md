# Финальная сборка Startup Club Bot

## 1. Перед заменой

1. Сделайте backup MySQL.
2. Сохраните свой `.env` отдельно. В архиве реального `.env` нет.
3. Не копируйте старый `__pycache__`.

## 2. База данных

Если предыдущую миграцию из `startup_bot_final_with_admin.zip` уже выполняли — запустите `migration_from_previous.sql`.

Если миграции ещё не выполнялись — запустите `migration_final.sql`.

После миграции новые мероприятия лучше создавать через `/admin`: бот сам заполнит БД и сохранит Telegram `photo_file_id` фотографии.

## 3. .env

Добавьте/проверьте:

```env
BOT_TOKEN=...
CHANNEL_ID=@StartupClubRTUMIREA
ADMIN_IDS=123456789
MYSQL_HOST=...
MYSQL_PORT=3306
MYSQL_USER=...
MYSQL_PASSWORD=...
MYSQL_DATABASE=dady_ru
COINS_PER_ATTENDANCE=3
WORKER_INTERVAL_SECONDS=60
```

## 4. Установка

```bash
python3 -m pip install -r requirements.txt
python3 bot.py
```

## 5. Что проверить после запуска

1. `/start` — регистрация.
2. ФИО `иВАНОВ` должно сохраниться как `Иванов`.
3. Код направления принимает `09.03.02`.
4. Группа принимает `ЭФБО-02-26`, а не просто `07`.
5. `/admin` — создать тестовое мероприятие с фото, аудиторией и ссылкой «Как добраться».
6. Убедиться, что мероприятие появилось в пользовательском разделе.
7. В админке открыть мероприятие → получить QR → открыть check-in → отсканировать зарегистрированным пользователем.
8. Проверить `reg.attended=1`, `reg.coins_awarded=1`, `users.coins += 3`.
9. Для теста 24-часового напоминания поставьте `events.start_date` в ближайшие 24 часа и `reg.reminder_24h_sent=0`.

## Важное про фото

В MySQL не нужно хранить бинарную картинку. Поле `events.photo_file_id` содержит Telegram `file_id`. При создании мероприятия админ отправляет фото боту, бот получает `file_id` и записывает его в БД. Telegram затем отдаёт то же фото по этому `file_id`.

Старый вариант с фото из канала тоже оставлен: пост с фото и меткой `#event_12` сохранит фото для мероприятия ID 12.
